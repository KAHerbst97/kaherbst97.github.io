Representing Numbers Using Continued Fractions and the TRIP Framework

  const abs = a => a<0n?-a:a;
  const gcd = (a,b) => {a=abs(a);b=abs(b);while(b!==0n)[a,b]=[b,a%b];return a;};
  const reduce = (a,b) => {if(b===0n)throw Error('Zero denominator.');if(b<0n){a=-a;b=-b;}const d=gcd(a,b);return [a/d,b/d];};
  const toFrac = v => v[1]===1n?String(v[0]):`${v[0]}/${v[1]}`;
  const latexFrac = v => v[1]===1n?String(v[0]):String.raw`\frac{${v[0]}}{${v[1]}}`;
  const matMul = (a,b) => a.map(row=>b[0].map((_,j)=>row.reduce((s,v,k)=>s+v*b[k][j],0n)));
  const matVec = (a,v) => a.map(row=>row.reduce((s,x,i)=>s+x*v[i],0n));
  const I = [[1n,0n],[0n,1n]], S=[[0n,1n],[1n,0n]];
  const V = [[0n,1n],[1n,1n]], Vinv=[[-1n,1n],[1n,0n]];
  const T0 = [[0n,1n],[1n,1n]], T1=[[1n,1n],[0n,1n]];
  const inverse = m => {const [[a,b],[c,d]]=m,det=a*d-b*c;if(abs(det)!==1n)throw Error('Invalid branch matrix.');return [[d/det,-b/det],[-c/det,a/det]];};

  const choose = (q,p) => {
    const q1=matVec(p.inv1,q),q0=matVec(p.inv0,q);
    // Shared endpoints belong to branch 1.
    if(q1.every(z=>z>=0n))return {branch:1,q:q1};
    if(q0.every(z=>z>=0n))return {branch:0,q:q0};
    throw Error('The orbit left both Farey branches.');
  };
  const MAX_SLOW = 2500;
  // Shared by the expansion and explorer: inverse branches, with branch 1
  // owning shared endpoints. A search limit is not proof of nontermination.
  function acceleratedStep(q,params){
    let z=q.slice(),k=0;
    const seen=new Set();
    while(true){
      const key=z.join(',');
      if(seen.has(key))return {reason:'inner-cycle',error:'The F₁ inverse orbit repeats without reaching branch 0; no accelerated digit exists here.'};
      seen.add(key);
      const move=choose(z,params);
      if(move.branch===0)return {q:move.q,k,steps:k+1};
      if(k===MAX_SLOW)return {reason:'slow-limit',error:`Search limit: no branch 0 within ${MAX_SLOW} branch-1 steps. The next digit may still exist.`};
      z=move.q;k++;
    }
  }
  function expand(x,params){
    let q=[x[1]-x[0],x[0]],digits=[],rows=[],status='digit-limit',period=null;
    const visited=new Map(),MAX_DIGITS=60;
    let total=0;
    for(let step=0;step<MAX_DIGITS;step++){
      const current=project(q);
      if(current[0]===0n){status='zero';break;}
      const key=q.join(',');
      if(visited.has(key)){status='period';period={start:visited.get(key),end:step};break;}
      visited.set(key,step);
      const move=acceleratedStep(q,params);
      if(move.error){status=move.reason;break;}
      q=move.q;total+=move.steps;
      const k=move.k,out=project(q);
      const H=matMul(matMul(matMul(V,mpow(params.B1,k)),params.B0),Vinv);
      const reconstructed=reduce(H[0][0]*out[0]+H[0][1]*out[1],H[1][0]*out[0]+H[1][1]*out[1]);
      if(reconstructed[0]*current[1]!==current[0]*reconstructed[1])throw Error('Exact reconstruction check failed.');
      digits.push(k);rows.push({current,next:out,k,H});
      if(out[0]===0n){status='zero';break;}
      if(visited.has(q.join(','))){status='period';period={start:visited.get(q.join(',')),end:step+1};break;}
    }
    return {digits,rows,status,period,last:project(q),total};
  }
  const fmtPoly=(a,b,name) => {

    if(b!==0n||parts.length===0){const sign=b<0n?'-':'+';const num=abs(b).toString();parts.push(parts.length?` ${sign} ${num}`:(b<0n?'-':'')+num);}
    return parts.join('');
  };

  };

    a = a < 0n ? -a : a;

What are continued fractions?

Consider an ordinary fraction,

\[ \frac{2}{17}=\cfrac{1}{8+\cfrac{1}{2}}=[0;8,2]. \]

Continued-fraction algorithms generate these expansions by repeatedly transforming numbers. The neat part is that we can describe these transformations using matrices, and this gives us a natural way to extend continued fractions to higher dimensions.

Representing fractions with vectors

A two-dimensional vector can represent a single fraction, or equivalently a point on the one-dimensional unit interval,

\[ \begin{pmatrix}p\\q\end{pmatrix} \longleftrightarrow x=\frac pq\in[0,1]. \]

Similarly, a three-dimensional vector can represent an ordered pair of fractions, or equivalently a point in the two-dimensional triangle

\[ \begin{pmatrix}q\\p\\r\end{pmatrix} \longleftrightarrow (x,y)=\left(\frac pq,\frac rq\right)\in\Delta, \qquad \Delta=\{(x,y):0\le y\le x\le1\}. \]

For example, \((10,8,3)^\top\) represents the point \((4/5,3/10)\) in the triangle. These are called homogeneous coordinates, multiplying every entry by the same positive constant leaves the represented point unchanged.

Remark: Higher Dimensions

The intuition extends naturally: one number lives on an interval and uses \(2\times2\) matrices; two numbers live in a triangle and use \(3\times3\) matrices; three numbers live in a tetrahedron and use \(4\times4\) matrices. More generally, an \(n\)-dimensional vector represents \(n-1\) numbers, corresponding to a point in an \((n-1)\)-dimensional simplex.

The Farey maps

We can generate ordinary continued-fraction expansions by iterating the Farey map, defined on the unit interval \([0,1]\). Although the input is a single number \(x\), each branch can be represented by a \(2\times2\) matrix acting on \((x,1)\),

\[ \begin{aligned} F_1(x) &=\frac{x}{1-x}, & \begin{pmatrix}1&0\\-1&1\end{pmatrix} \begin{pmatrix}x\\1\end{pmatrix} &=\begin{pmatrix}x\\1-x\end{pmatrix}, &&0<x\le\frac12,\\[10pt] F_0(x) &=\frac{1-x}{x}, & \begin{pmatrix}-1&1\\1&0\end{pmatrix} \begin{pmatrix}x\\1\end{pmatrix} &=\begin{pmatrix}1-x\\x\end{pmatrix}, &&\frac12<x\le1. \end{aligned} \]

Taking the ratio of the two entries in each resulting vector recovers the corresponding map. Applying \(F_1\) exactly \(k\) times and then \(F_0\) gives an accelerated (Gauss-type) step, \(G_k=F_0\circ F_1^k\).

For our original fraction,

\[ \frac{2}{17}\xrightarrow{G_7}\frac12 \xrightarrow{G_1}0. \]

The successive indices \(k=7,1\) correspond to the ordinary continued-fraction digits \(8,2\).

We can extend the same idea to the triangle \(\Delta\). Now the input is an ordered pair \((x,y)\), and the corresponding Farey map has two branches represented by \(3\times3\) matrices acting on \((1,x,y)\),

\[ \begin{aligned} F_1(x,y) &=\left(\frac{x}{1-y},\frac{y}{1-y}\right), & \begin{pmatrix} 1&0&-1\\ 0&1&0\\ 0&0&1 \end{pmatrix} \begin{pmatrix}1\\x\\y\end{pmatrix} &= \begin{pmatrix}1-y\\x\\y\end{pmatrix}, &&x+y\le1,\\[12pt] F_0(x,y) &=\left(\frac{y}{x},\frac{1-x}{x}\right), & \begin{pmatrix} 0&1&0\\ 0&0&1\\ 1&-1&0 \end{pmatrix} \begin{pmatrix}1\\x\\y\end{pmatrix} &= \begin{pmatrix}x\\y\\1-x\end{pmatrix}, &&x+y>1. \end{aligned} \]

This time, dividing the second and third entries by the first recovers the transformed pair. Just as the interval is partitioned into branches that generate continued-fraction digits, the triangle is partitioned into regions that generate a sequence describing two numbers together.

What are the TRIP maps?

TRIP maps modify the matrices used to construct Farey subdivisions, producing different continued-fraction algorithms on intervals, triangles, and higher-dimensional simplices.

The construction uses permutation matrices, which rearrange entries in a vector. The notation \(e\) means leave the order unchanged; \((12)\) swaps the first and second entries; and \((123)\) cycles three entries. For example,

\[ \underbrace{\begin{pmatrix}0&1\\1&0\end{pmatrix}}_{P_{(12)}} \begin{pmatrix}a\\b\end{pmatrix} =\begin{pmatrix}b\\a\end{pmatrix}, \]

while

\[ \underbrace{\begin{pmatrix}0&0&1\\1&0&0\\0&1&0\end{pmatrix}}_{P_{(123)}} \begin{pmatrix}a\\b\\c\end{pmatrix} =\begin{pmatrix}c\\a\\b\end{pmatrix}. \]

Starting from the two Farey subdivision matrices \(T_0,T_1\), which encode the inverse-branch construction, we choose a triple of permutations \((\sigma,\tau_0,\tau_1)\) and construct

\[ F_0=P_\sigma T_0P_{\tau_0}, \qquad F_1=P_\sigma T_1P_{\tau_1}. \]

The choice \((e,e,e)\) recovers the original Farey construction in the corresponding dimension. Other triples modify the branch maps, potentially changing the partitions and digit expansions of the same point.

For intervals, we use \(2\times2\) matrices and have two possible permutations, giving \(2^3=8\) choices. For triangles, we use \(3\times3\) matrices and have six permutations, giving \(6^3=216\) TRIP maps. The same principle extends to higher-dimensional simplices.

From Farey branches to Gauss regions

Each Farey step subdivides the interval or triangle into two regions, labeled \(0\) and \(1\). Repeating this process gives a binary sequence recording which branch contains a point at each step.

The accelerated Gauss map groups consecutive applications of branch \(1\), followed by branch \(0\), into a single step. This produces regions labeled by nonnegative integers,

Gauss region Farey branches Meaning
\(\Delta_0\) \(0\) No \(1\) steps before \(0\)
\(\Delta_1\) \(10\) One \(1\) step before \(0\)
\(\Delta_2\) \(110\) Two \(1\) steps before \(0\)
\(\Delta_3\) \(1110\) Three \(1\) steps before \(0\)
\(\vdots\) \(\vdots\) \(\vdots\)

More precisely, let \(V\) contain the vertices of our original interval or triangle in homogeneous coordinates. The region \(\Delta_k\) is constructed from

\[ VF_1^kF_0, \qquad k=0,1,2,\ldots, \]

by projecting its columns back into the interval or triangle. Thus, the region number \(k\) counts how many times branch \(1\) occurs before branch \(0\), rather than describing the region’s geometric position.

A Farey itinerary such as

\[ 110\,10\,1110\,0\cdots \]

therefore becomes the accelerated sequence

\[ (2,1,3,0,\ldots). \]

This is the connection to ordinary continued fractions, instead of tracking every binary subdivision individually, we record how many consecutive steps occur before switching branches. The same idea works on triangles, even though their geometry is considerably more complicated.

Families

For 3d we have 216 permutation settings falling into 15 families of subdivision patterns and

  • Same family: their partition lines match at every depth, either directly or after rearranging the triangle’s three outer vertices.
  • Different families: no rearrangement of the outer vertices makes their partition lines match.

There are 6 ways to arrange three vertices, but multiple permutation settings can produce the same partition even without rearranging them. Consequently, families contain more than six settings: 12 families contain 12 settings each, and 3 contain 24 each, accounting for all 216.

Each family therefore has one representative picture. Its members share that geometry, but may label the pieces differently and move points differently.
