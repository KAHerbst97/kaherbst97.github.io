Intro

Consider a situation where we have several endpoints of possibly mixed type but we can order these endpoints on a priority/hierarchical scale

Example (clinical setting)

Clinicians may order outcomes by importance. For example, when considering treatment of limb-ischemia (a blood clot/reduction of blood flow in a major limb) they may consider a priority ordering such as,

  1. Time to all-cause death
  2. Time to stroke
  3. Time to Affected Limb Amputation
  4. Time to myocardial infarction (MI)
  5. Time to in-patient (>24h not for amputation) hospitalization
  6. Pointwise rate of rescue intervention usage
  7. Change from baseline in a quality-of-life score
Example (reliability/operations research)

We may order outcomes by severity/cost such as,

  1. Time to Catastrophic failure / safety incident (e.g., time to injury, fire or regulatory reportable event)
  2. Time to Unplanned shutdown (time to first line-stop or critical system trip)
  3. Warranty-return event (time to first return/claim attributable to failure)

If we have treatments that we want to compare according to their performance on such ordered scales we have several options that I give a short overview on here

Using the below example we show how to use each method,

1) Global (equi-importance) methods

These are “global statistical tests” for multiple endpoints that consider each outcome individually and then produce a single to represent all outcomes across all individuals (which would allow us to easily use a univariate test on the final composite). They consider each endpoint on the same priority level, ignoring hierarchy

1a) O’Brien (Rank Sum of endpoint-wise ranks across all endpoints individually)

O’Brien creates a patient-level score by ranking each endpoint separately and then summing those ranks, treating all endpoints as the same “priority level” (unless you add weights).

Let \(Y_{ijk}\) be endpoint \(k\) for subject \(j\) in group \(i\), and let \(R_{ijk}\) be the pooled rank of \(Y_{ijk}\) among all subjects for endpoint \(k\) (ties get midranks). Define \[S_{ij}=\sum_{k=1}^K R_{ijk}\] Then compare the observed \({S_{ij}}\) between treatment arms using Wilcoxon rank-sum / Mann–Whitney \(U\). The interpretation is: treatment is tested for a shift in a latent additive rank-utility (the sum of endpoint-wise ranks). There is no explicit hierarchical priority, each endpoint contributes additively.

The observed \(W_T=14\), and the subsets of \(3\) ranks with sum at least as large (\(\ge 14\)) are exactly the \(11\) subsets: \[ \{5,6,7\},\{4,6,7\},\{3,6,7\},\{2,6,7\},\{1,6,7\}, \] \[ \{4,5,7\},\{3,5,7\},\{2,5,7\},\{3,4,7\},\{4,5,6\},\{3,5,6\} \] Therefore the exact one-sided p-value is \[ p=\Pr(W_T\ge 14)=\frac{11}{35}\approx 0.314. \]

and, \[ p_{\text{asym}}(T)=P(Z\ge Z_T)=1-\Phi(0.7071)\approx 0.2398, \]

1b) Sun (Average Z-score across all endpoints individually)

Sun et al. create a patient-level score by putting endpoints onto a common standardized scale and averaging, again treating endpoints as the same “priority level” (unless you add weights).

  • First align direction so that “larger is better” for every endpoint; for time-to-event endpoints, one typically replaces \((t,\delta)\) by a logrank/Gehan-type score so censoring is handled appropriately.
  • Standardize each endpoint \(k\) across all subjects: \[Z_{ik}=\frac{X_{ik}-\bar X_k}{s_k}\]
  • Form the average Z-score: \[A_i=\frac{1}{K}\sum_{k=1}^K Z_{ik}\]
  • Compare \({A_i}\) across arms via Wilcoxon rank-sum / Mann–Whitney \(U\)

Interpretation: treatment is tested for a shift in a latent additive standardized utility (the average of standardized component scores). Again, like O’Brien, this does not encode a hierarchy unless you explicitly weight endpoints.

Example (demonstrative example)

First we align all directions,

  • For endpoints where “bigger is better”: use the value as-is (Death, Stroke, Amp, MI, Hosp, QoL).
  • For Rescue rate where “smaller is better”: use (\(X_{\text{Rescue}^\star}=-\text{Rescue}\)) so larger is better.

For the censored ((365)), we have the option to treat it as 365 but Sun et al. discuss logrank-type scoring for censoring which we opt to perform. That is we’ll implement the “logrank-type scoring” explicitly for the 5 time-to-event endpoints (Death/Stroke/Amp/MI/Hosp), then do regular Z-standardize on the \(2\) others For each time endpoint (\(k\)), each subject has (\((t_{ik},\delta_{ik})\)) where (\(\delta=1\)) if the event is observed and (\(\delta=0\)) if censored at 365.

Use the pooled Nelson–Aalen cumulative hazard for endpoint (k): \[\widehat\Lambda_k(t)=\sum_{t_{(j)}\le t}\frac{d_j}{Y_j}\] where (\(t_{(j)}\)) are distinct event times, (\(d_j\)) is the number of events at (\(t_{(j)}\)) (here always 1), and (\(Y_j\)) is the pooled risk set size just before (\(t_{(j)}\)).

A simple per-subject logrank-type score (a monotone transform of the Cox/no-covariate score residual) is \[L_{ik}=\widehat\Lambda_k(t_{ik})-\delta_{ik}\] This has the right direction: larger (\(L_{ik}\)) = better (late censoring gives large (\(\widehat\Lambda\)) with (\(\delta=0\)); early events give small (\(\widehat\Lambda\)) but (\(\delta=1\)), so negative).

2) Hierarchical methods

2a) Felker (Hierarchical Composite)

Felker defines a single ordinal rank per patient using the pre-specified hierarchy and within ordering then compares arms using a rank test.

  • Construct a ranking map \(R_i=g(Y_i)\), where \(Y_i\) is the patient’s outcome vector.
  • Compare \(\{R_i\}\) across arms using Wilcoxon rank-sum / Mann–Whitney (equivalent).

Key feature: the hierarchy is built into \(g(\cdot)\). Lower-priority endpoints are used only to break ties among higher-priority outcomes.

Example (demonstrative example)

Using our data above we perform the global rank test indicated above with g defined as \[g(Y_i) = R_i^{\text{global}} = 1 + \# \{j: Y_j \prec Y_i\}\] where \(\succ\) and \(\prec\) are a lexicographic ordering where two patients \(i\) and \(j\) we have \(i \succ j\) iff at the first component they different in the hierachy (in order) \(i\) is better.

id Death[h1] Stroke[h2] Amp[h3] MI[h4] Hosp[h5] Rescue rate[h6] QoL Δ[h7]
T1 300 120 200 180 150 0.10 -7
T2 (365) 80 (365) (365) 120 0.20 +2
T3 (365) (365) (365) (365) (365) 0.05 +8
C1 (365) 100 (365) 200 220 0.10 -3
C2 330 210 230 100 10 0.25 +2
C3 (365) (365) (365) (365) (365) 0.15 -5
C4 130 40 (365) 20 30 0.15 -6

Here according to our ordering the global best to worst ordering is \[T3 \succ C3 \succ C1 \succ T2 \succ C2 \succ T1 \succ C4\]

This global ordering is determined by going event-by-event and comparing remaining contenders. Numerically, if we assign higher ranks to better outcomes (according to the lexicographic ordering), we obtain

  • Treatment: \(R_T={2,4,7}\)
  • Control: \(R_C={1,3,5,6}\)

The Wilcoxon rank sums are \[ W_T = 2+4+7 = 13,\qquad W_C = 1+3+5+6 = 15. \]

With \(n_T=3\) and \(n_C=4\), the corresponding Mann–Whitney \(U\) statistics (using the shift relationship) are \[ U_T = W_T - \frac{n_T(n_T+1)}{2} = 13 - \frac{3\cdot 4}{2} = 13-6 = 7, \] \[ U_C = W_C - \frac{n_C(n_C+1)}{2} = 15 - \frac{4\cdot 5}{2} = 15-10 = 5. \]

Among the \(n_Tn_C=3\cdot 4=12\) cross-arm comparisons induced by this global ordering, treatment has \(U_T=7\) “wins” and control has \(U_C=5\) “wins.” The induced probability-of-treatment-superiority parameter is estimated by \[ \hat\theta_T = \frac{U_T}{n_T n_C} = \frac{7}{12} \approx 0.5833, \] and equivalently \[ \hat\theta_C = \frac{U_C}{n_T n_C} = \frac{5}{12} \approx 0.4167. \]

To determine the exact one-sided p-value (in the direction “treatment tends to have larger ranks”), note that treatment could be any \(3\) of the \(7\) ranks with assumed equal probability under the null of exchangeability \(F_T=F_C\), so there are \(\binom{7}{3}=35\) equally likely allocations. The observed \(U_T=7\) is equivalent to \(W_T=13\), and the subsets of \(3\) ranks with sum at least as large (\(\ge 13\)) are exactly the \(15\) subsets: \[ \{1,5,7\},\{1,6,7\},\{2,4,7\},\{2,5,6\},\{2,5,7\}, \] \[ \{2,6,7\},\{3,4,6\},\{3,4,7},\{3,5,6\},\{3,5,7\}, \] \[ \{3,6,7\},\{4,5,6\},\{4,5,7\},\{4,6,7\},\{5,6,7\} \] Therefore the exact one-sided p-value is \[ p_T=\Pr(U_T\ge 7)=\Pr(W_T\ge 13)=\frac{15}{35}\approx 0.4286. \] This is equivalent to focusing on controls: \[ p_C=\Pr(U_C\le 5)=\Pr(12-U_T\le 5)=\Pr(U_T\ge 7)=\frac{15}{35}\approx 0.4286. \]

For larger samples we typically do not enumerate all \(\binom{n_T+n_C}{n_T}\) allocations. Instead we use the normal approximation for the Mann–Whitney \(U\)-statistic. Under \(H_0\) (exchangeability), the null mean and variance are \[ \mathbb E_0[U_T]=\frac{n_T n_C}{2},\qquad \operatorname{Var}_0(U_T)=\frac{n_T n_C (n_T+n_C+1)}{12}. \] Equivalently, for the rank-sum \(W_T\), \[ \mathbb E_0[W_T]=\frac{n_T(n_T+n_C+1)}{2},\qquad \operatorname{Var}_0(W_T)=\frac{n_T n_C (n_T+n_C+1)}{12}. \] So a large-sample \(z\)-statistic for “treatment better” is \[ Z=\frac{U_T-\frac{n_T n_C}{2}} {\sqrt{\frac{n_T n_C (n_T+n_C+1)}{12}}} \overset{H_0}{\sim}N(0,1). \]

In this toy example, \(n_T=3\), \(n_C=4\), \(U_T=7\), so the normal approximation yields \[ Z=\frac{7-6}{\sqrt{3\cdot4\cdot (3+4+1)/12}}=\frac{1}{\sqrt{8}}\approx 0.3536, \] and a one-sided p-value of \[ p_{\text{asym}}(T)=\Pr(Z\ge 0.3536)=1-\Phi(0.3536)\approx 0.362. \] This differs from the exact value \(15/35\approx 0.4286\) because the normal approximation is poor at such small \(n\), which is why the exact enumeration is preferable here.

2b) Modified Kernel + U-statistic “Win” methods

Just as Felker U statistics built from a pairwise kernel taking in both treatment and control patients and comparing them while considering the hierarchy specifically

Using this pairwise kernel across every treated–control pair \((i,j)\) in the specified priority order decides win (\(+1\)), loss (\(−1\)), or tie/indeterminate (\(0\)) then aggregating over pairs gives us the standard win statistic building blocks. These aggregated kernel comparisons are naturally order-2 U-statistics

Example (win kernels and U-statistics)

Fix a prioritized pairwise comparison kernel on full patient outcome records (possibly multivariate, with hierarchy/censoring rules built in). In a two-arm trial this is naturally written as a two-sample order-2 kernel \(\phi:\mathcal Z_T\times\mathcal Z_C\to\{-1,0,+1\}\) (win/tie/loss), or \({0,1}\) if you only code “treated wins.”

For treated patient \(i\) and control patient \(j\), define the pairwise score \[ s_{ij}=\phi(Z_i,W_j)\in{-1,0,+1}, \] where \(+1\) means “treated wins,” \(-1\) means “treated loses,” and \(0\) means tie/indeterminate. The win statistic is the average of this kernel over all treated–control pairs, \[ U=\frac{1}{n_T n_C}\sum_{i=1}^{n_T}\sum_{j=1}^{n_C}\phi(Z_i,W_j), \] which is exactly a two-sample order-2 U-statistic. (Many practical variants—stratified/matched designs, inverse-probability weighting, nuisance-adjusted estimators—keep the same underlying order-2 kernel but modify how pairs are aggregated.)

A standard hierarchical kernel is lexicographic for example,

  1. Compare Death (larger time is better); if resolved, stop.
  2. Else compare Stroke; if resolved, stop.
  3. Else Amp; then MI; then Hosp.
  4. Else Rescue (smaller is better).
  5. Else QoL (\(\Delta\)) (larger is better).

Its useful to note that in general censoring can occur when the ordering cannot be determined for an endpoint and you move on.

2b1) Finkelstein–Schoenfeld (FS) net benefit / win difference

FS aggregates the pairwise scores: \[U = \frac{1}{n_T n_C}\sum_{i=1}^{n_T}\sum_{j=1}^{n_C} s_{ij}\] Here \(U\) targets \[E[U]=P(\text{win})-P(\text{loss})\] often called net benefit / win difference / net treatment benefit

Example (demonstrative example)

Compute \(s_{ij}\) for all \(n_T n_C = 3\cdot 4=12\) treated–control pairs. The table also records which endpoint first resolved the comparison. Define the estimator \[\hat\Delta =\frac{1}{n_T n_C}\sum_{i=1}^{n_T}\sum_{j=1}^{n_C} s_{ij} =\widehat{P(\text{win})}-\widehat{P(\text{loss})}\] (where ties/indeterminates contribute 0 to the difference).

This is a two-sample U-statistic. A standard asymptotic variance estimator uses the Hoeffding projection:

Compute row/column averages \[\bar s_{i\cdot}=\frac{1}{n_C}\sum_{j=1}^{n_C} s_{ij},\qquad \bar s_{\cdot j}=\frac{1}{n_T}\sum_{i=1}^{n_T} s_{ij}\]

Then an asymptotic estimator of \(\mathrm{Var}(\hat\Delta)\) is \[\widehat{\mathrm{Var}}(\hat\Delta) =\frac{1}{n_T(n_T-1)}\sum_{i=1}^{n_T}\left(\bar s_{i\cdot}-\hat\Delta\right)^2 + \frac{1}{n_C(n_C-1)}\sum_{j=1}^{n_C}\left(\bar s_{\cdot j}-\hat\Delta\right)^2\]

So \[SE(\hat\Delta)=\sqrt{\widehat{\mathrm{Var}}(\hat\Delta)}, \qquad Z=\frac{\hat\Delta}{SE(\hat\Delta)}\approx N(0,1)\ \text{under }H_0\] and a Wald CI is \[\hat\Delta \pm z_{1-\alpha/2}, SE(\hat\Delta)\] Though in cases with a small amount of patients we can find the direct CI and P-values as we do below using permutations.

Therefore, \[p = P(\#W \ge 7) = P!\left(\sum_{i,j}s_{ij}\ge 2\right) = \frac{15}{35}\approx 0.4286\]

(Here, because there are no ties/indeterminates, \(\#W\) is exactly the Mann–Whitney \(U_T\)) on the induced ordering, so the same exact p-value appears.)

2b2) Pocock win ratio

The win ratio emphasizes the ratio of win to loss probabilities: \[WR =\frac{P(\text{win})}{P(\text{loss})} \approx \frac{\#W}{\#L}\] typically with the same hierarchical comparison kernel. It is a function of two U statistics with kernels ????

Example (demonstrative example)

From the pairwise table above, \(\#W=7\) and \(\#L=5\), so \[\widehat{WR}=\frac{7}{5}=1.4\]

Interpretation: in this sample, treated patients win about 1.4 times as often as they lose when compared pairwise against controls under the prioritized endpoint hierarchy.

Let \[\hat p_W=\frac{\#W}{n_T n_C},\qquad \hat p_L=\frac{\#L}{n_T n_C}, \qquad \widehat{WR}=\frac{\hat p_W}{\hat p_L}=\frac{\#W}{\#L},\] ignoring ties in numerator/denominator (ties just reduce \(\#W+\#L\) below \(n_Tn_C\)).

Large-sample inference is typically done on \(\log(WR)\). One common approach (used in generalized pairwise comparison software) again treats this as a U-statistic functional and uses influence-function / projection variance. A simple, serviceable approximation that is often used when ties are not dominant is a delta-method style: \[\widehat{\mathrm{Var}}(\log \widehat{WR}) \approx \frac{\widehat{\mathrm{Var}}(\hat p_W)}{\hat p_W^2} + \frac{\widehat{\mathrm{Var}}(\hat p_L)}{\hat p_L^2} -2\frac{\widehat{\mathrm{Cov}}(\hat p_W,\hat p_L)}{\hat p_W\hat p_L}\] where \(\widehat{\mathrm{Var}}(\hat p_W)\), \(\widehat{\mathrm{Var}}(\hat p_L)\), and the covariance are computed via the same projection idea (replace \(s_{ij}\) with indicators (\(I{s_{ij}=+1}\) and \(I{s_{ij}=-1})\).

Concretely define \[w_{ij}=I(s_{ij}=+1),\qquad \ell_{ij}=I(s_{ij}=-1)\] Then \(\hat p_W=\frac{1}{n_Tn_C}\sum w_{ij}\) and \(\hat p_L=\frac{1}{n_Tn_C}\sum \ell_{ij}\) are again two-sample U-statistics, and you can estimate \(\mathrm{Var}(\hat p_W)\) and \(\mathrm{Var}(\hat p_L)\) using the same row/column projection formula as above (with \(w_{ij}\) or \(\ell_{ij}\) in place of \(s_{ij}\)), and similarly estimate \(\mathrm{Cov}(\hat p_W,\hat p_L)\) via cross-products of the corresponding row/column means.

Then \[SE(\log \widehat{WR})=\sqrt{\widehat{\mathrm{Var}}(\log \widehat{WR})},\] a Wald CI on the log scale is \[\log \widehat{WR}\pm z_{1-\alpha/2}SE(\log \widehat{WR}),\] and exponentiating gives a CI for (WR).

Practical note: in real analyses, most people either (a) use the established generalized pairwise comparison variance estimator (projection-based) implemented in software, or (b) use a permutation/randomization test if the design supports it, or (c) use a bootstrap (cluster bootstrap if clustered).

2c) DOOR (Desirability of Outcome Ranking) and related “benefit–risk ranking” frameworks

Core idea

Construct an ordinal desirability ranking that jointly encodes benefit and harm categories, then compare arms via a probability-of-better-outcome estimand (again essentially a Mann–Whitney-type object).

DOOR is widely used in infectious diseases and emphasizes explicit benefit–risk tradeoffs in the ranking categories. (OUP Academic)

Where your tied-tier rules fit

DOOR is basically a global rank framework with carefully designed categories. If you allow co-ranked regions, your rules determine:

  • how categories are formed (or how ties within a category are broken),
  • whether you treat multi-attribute categories as Pareto/majority/score-based.

So your framework generalizes DOOR too, but most DOOR applications bake the rule into the category definitions.
