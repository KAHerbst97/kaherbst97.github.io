Principles of Experimental Design

“The TV scientist who mutters sadly ‘The experiment is a failure: we have failed to achieve what we hoped for,’ is suffering mainly from a bad scriptwriter. An experiment is never a failure solely because it fails to achieve predicted results. An experiment is a failure only when it also fails adequately to test the hypothesis in question, when the data it produces don’t prove anything one way or the other.

— Robert M. Pirsig, Zen and the Art of Motorcycle Maintenance (1974)

Phase II vs. III

The simplest and most common phase II trials are nonrandomized one arm studies comparing a new therapy to a historical controls effectiveness; Phase III trials are overwhelmingly randomized with concurrent control.

We can find two-stage designs by iteration, using the following

We identify two-stage designs with the following iteration.

Given \((p_0, p_1, \alpha^\star, 1-\beta^\star)\)

Making a function for \(P(\text{Reject } H_0|p)\),

## reject iff X1 > a1 and X1 + X2 >= a
rej = function(p, a1, a, n1, n2) {
  acc = pbinom(a1, n1, p)
  lo = a1 + 1L; hi = n1
  if (lo <= hi) {
    i = lo:hi
    s1 = dbinom(i, n1, p)
    s2 = pbinom(a - i, n2, p)
    acc = acc + sum(s1*s2)
  }
  1 - acc
}

then we can use this to find \(\alpha,\beta\) for any specified design \((a_1,a,n_1,n_2)\) and using simple loops we can catalogue all designs that work with total sample size under some specific \(n=n_1+n_2\)

find_two_stage <- function(p0, p1,
                           alpha_star = 0.05, power_star = 0.85,
                           nmin = 10, nmax = 50) {
  out <- list(); k <- 1
  for (n in nmin:nmax) {
    for (n1 in 1:(n - 1)) {
      n2 <- n - n1
      for (a1 in 0:(n1 - 1)) {
        # here we start at (a1) to match clinfun
        # in general a1=a is one stage
        for (a in (a1):(n - 1)) {
          alpha <- rej(p0, a1, a, n1, n2)
          power <- rej(p1, a1, a, n1, n2)
          if (alpha <= alpha_star && power >= power_star) {
            pet0 <- pbinom(a1, n1, p0)       
            en0  <- n1 + (1 - pet0) * n2   
            out[[k]] <- data.frame(
              a1, a, n1, n2, n,
              alpha = as.numeric(alpha),
              power = as.numeric(power),
              PET_p0 = pet0,
              EN_p0  = en0
            )
            k <- k + 1L
          }}}}}
  do.call(rbind, out)
}

Jung’s Admissible Designs

Our optimal design may have high total sample size and the minimax design may have high \(EN(p_0)\) relative to the optimal and vice versa - Admissible designs seeks to balance the two goals using some weight, identifying the specific design \(d \in \mathcal{D}\) st with a particular weight \(q\in [0,1]\) we seek,

\[d^{admissible} = argmin_{d\in\mathcal{D}}\{q(n(d)) + (1-q)EN(d|p_0)\}\]

Again the package is useful here,

Phase II Trials: Binary Outcome

If our response is binary and we are interested in the population proportion of response under a new therapy \((p)\) then we usually want to establish that our treatment is better than some historical controls estimated proportion \((p_0)\)

Simon’s Two Stage Phase II Trial w/ Futility Stopping

If we know our targets \(\alpha^*, 1-\beta^*\) and specific alternative effectiveness \(p_1\) that we want to test, \[\boxed{H_0:p = p_0,\quad H_1: p = p_1}\] then noting that the counts in each stage are independent \(X_1 \perp\!\!\!\perp X_2\), finding a two stage regime with futility stopping is simply choosing sample sizes \((n_1,n_2)\) at each stage and cutoffs \((a_1,a)\) such that \[\begin{aligned}\alpha^* &\geq P(X_1>a_1,X_1+X_2>a|p_0)\\ 1-\beta^* &\leq P(X_1>a_1, X_1+X_2>a|p_1) \end{aligned}\]
