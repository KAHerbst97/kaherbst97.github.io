Shared Concepts in Statistical Models

?

We consider statistical models as collections of probability distributions that impose assumptions on the distributions of variables and their relationships to draw inferences about a population. The relationships estimated by these models are associational unless a causal interpretation is justified by the study design and identification assumptions. We also discuss models as descriptive and predictive tools.

We can simply think of this as putting a model form on some of the parameters in a parametric statiscal model

  • Linear regression with normally distributed errors.

    \[ \mathcal P = \left\{ P_{\beta,\sigma}: Y\mid X=x\sim N(x^T\beta,\sigma^2), \; \beta\in\mathbb R^p, \; \sigma>0 \right\}. \]

    Here, \(\theta=(\beta,\sigma)\) has dimension \(p+1\). For fixed \(p\), this is a parametric model.

  • Generalized linear model with canonical link. \[ \mathcal P = \left\{ P_\beta: f(y\mid X=x;\theta) = \exp\left\{ \frac{y\,\theta-b(\theta)} {a(\phi)} +c(y,\phi) \right\}, \; \beta\in\mathbb R^p \right\}, \]

    We linearize the parameter \(\theta\) into the canonical parameter \(x^T\beta\),

    \[ \mathcal P = \left\{ P_\beta: f(y\mid X=x;\beta) = \exp\left\{ \frac{y\,x^T\beta-b(x^T\beta)} {a(\phi)} +c(y,\phi) \right\}, \; \beta\in\mathbb R^p \right\}, \]

    and if \(\mu(x)=E(Y\mid X=x)\), the canonical link \(g\) satisfies

    \[ g\{\mu(x)\}=\theta = x^T \beta \]

    So the mean is characterized by the inverse link of the linear parameter \(\theta(x) = x^T \beta\). The model is indexed by the finite-dimensional regression parameter \(\beta\in\mathbb R^p\) and is therefore a \(p\)-dimensional parametric model when \(p\) is fixed (assuming any dispersion parameter \(\phi\) is known or fixed).

Generalized Linear Models (GLMs)

I think statitcal modelling can be summarized pretty well by simply adding a model form (usually on the mean) to the staitical model,

A statistical model is a collection of probability distributions for the observed data, intended to represent the data-generating mechanisms (DGPs) we consider plausible. We may write a statistical model as

\[ \mathcal P = \{P:P\text{ satisfies the assumptions of the model}\}. \]

A model is called parametric if it can be indexed by a fixed finite-dimensional parameter,

\[ \mathcal P = \{P_\theta:\theta\in\Theta\}, \qquad \Theta\subseteq\mathbb R^d, \]

for some fixed positive integer \(d\). The set \(\Theta\) is called the parameter space and \(d\) is its dimension. Thus, the defining feature of a parametric model is that the unknown distribution is indexed by finitely many real-valued parameters.

A genome-wide association study (GWAS) examines whether single-nucleotide polymorphisms (SNPs), locations in DNA where individuals can differ by a single nucleotide (e.g., A versus G), are associated with a particular trait or disease. There are generally thousands or even millions of these SNPs to investigate in a genome for each individual.

Humans generally have 23 pairs of chromosomes, including 22 pairs of autosomes and one pair of sex chromosomes. For each autosomal pair, an individual inherits one chromosome from their mother and one from their father. These two chromosomes contain corresponding DNA sequences at the same locations, but the sequences are not necessarily identical. In particular, an individual may inherit different nucleotides from each parent at the same location in the genome.

A single-nucleotide polymorphism (SNP) is a location in DNA where the nucleotide varies across individuals in a population (e.g., A versus G). Because an individual has two copies of each autosomal chromosome, they carry two alleles at each SNP location, one inherited from each parent.

A genome-wide association study (GWAS) examines whether these genetic differences are statistically associated with particular traits or diseases. This is done by measuring the genotypes of many individuals at a large number of SNP locations across the genome and testing whether differences in genotype at each SNP are associated with differences in the outcome of interest.

GWAS data are usually high dimensional with many more SNP collected than individuals \(p>>n\) so storing the data in linked files is easier. This is the PLINK format.

For each individual and every SNP, researchers record their genotype using a table like the one above in the genotype matrix

File Information Structure
.bed Genotype matrix \(n \times p\) matrix of allele counts (0, 1, 2, or missing)

To compare individuals with different genotypes to determine whether they also differ in a particular trait or disease outcome. they match up each SNP using the snp info/assignment matrix

File Information Structure
.bim SNP (variant) information \(p \times 6\) table, one row per SNP
.fam Individual information \(n \times 6\) table, one row per individual

The six columns of .bim and .fam files follow a standardized order defined by PLINK. The .bim file identifies the genetic variants, while the .fam file identifies the individuals and contains basic individual-level information.

Column .bim — Variant information .fam — Individual information
1 CHR: Chromosome FID: Family ID
2 SNP: Variant identifier IID: Individual ID
3 CM: Genetic map position (centimorgans) PID: Paternal ID
4 BP: Physical position (base pairs) MID: Maternal ID
5 A1: Allele 1 SEX: Sex
6 A2: Allele 2 PHENO: Phenotype

Suppose we want to investigate whether a SNP is associated with diabetes. We record each individual’s genotype (AA, AG, or GG) and whether they have diabetes. We can then fit a logistic regression model,

\[ \operatorname{logit}\{P(Y_i=1\mid G_{ij},X_i)\} = \alpha_j+\beta_jG_{ij}+\gamma_j^\top X_i, \]

where \(Y_i\) indicates diabetes status, \(G_{ij}\in\{0,1,2\}\) is the number of G alleles individual \(i\) carries at SNP \(j\), and \(X_i\) contains relevant covariates such as age, sex, and genetic ancestry. Testing \(H_0:\beta_j=0\) determines whether the SNP is statistically associated with diabetes under this additive model.

This process is repeated separately for each SNP across the genome, allowing researchers to identify genetic locations associated with the outcome. Because so many hypothesis tests are performed, multiple-testing corrections are necessary. Importantly, finding an association does not establish that the SNP itself causally affects the disease.
